# 开始使用pywebbridge

## 简述
pywebbridge是一个在python中以对象级的精细度操作网页中的内容的web库
**万物皆对象**,所以网页也可以是一个可操作的对象

## 文件结构
pywebbridge/

## 开始使用

### 启动
首先导入:
```python
import pywebbridge
```
然后创建一个Flask服务器:
```python
服务器=pywebbridge.桥接服务器()
```

你需要一个处理相关连接的函数,框架会给处理函数传入网页中的`window`对象的引用
原版的`route`保持原样,需要路由一个使用桥接的页面路由时,使用`桥接页面路由`
```python
@服务器.桥接页面路由('/')
def 处理函数(window:pywebbridge.window):
    '你自己的处理代码'
```

### 编写页面
使用pywebbridge开发网页时,代码写起来很像`.js`
然后你可以按照js里的习惯进行操作,比如
```python
from pywebbridge.元素 import div,h1,p
主页面=div({'className':'页面'},
    h1({'className':'标题'},'欢迎使用pywebbridge'),
    p({'className':'正文'},'这是一个web工具库'),
    'pip install pywebbridge'
)

#此处为专用的将组件描述创建为element的函数,并非原版createElement
元素=window.document.创建元素(主页面)

window.document.body.appendChild(元素)
```

或者使用专用的描述兼容的操作函数
```python
window.document.body.追加子节点(元素)
```

功能上对应js的这两个函数
```js
document.createElement(...)
document.body.appendChild(...)
```

你还可以直接在你的HTML文本里直接放入元素描述
```python
window.document.body.追加子节点(
f'''<div className="页面">
    {h1({'className':'标题'},'<strong>欢迎使用pywebbridge</strong>')}
    {p({'className':'正文'},'这是一个web工具库')}
    pip install pywebbridge
</div>
'''
)
```

### 自定义页面组件
手写html和元素语法糖效果同(每次新建)

```python
class 组件A(预制件):
    '最好不要每次操作都新建,建议连接进入后提前创建好对应元素'
```
